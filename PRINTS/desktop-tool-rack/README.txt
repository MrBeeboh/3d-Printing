Summary:
Desktop Tool Rack Organiser for small hand toolsMay also have other uses : pen holder, artist’s paint brush holder etc.There are two different top plate versions for this. Custom Top PlateThe one shown in the photos is a custom top plate for my own selection of tools. This should be useful for many tools and items.General Top PlateAs an alternative, I designed a general top plate, which is basically a grid. There are also some inserts to adapt the square apertures to make them more useful for smaller toolsI haven’t printed out the full version of the general top, but I did do some tests to make sure the inserts fit and there is a CAD render to show what is looks like with and without the inserts.For both versions there are some options that you can print for the sides. A small side rack for pens etc and a screw in reel holder for wire/solder etc.Base.stl        - The base partSidePanel.stl   - Side panels, print two of theseCustomTop.stl   - Top panel as shower in the photos (custom version)AllenKeyStandoffs.stl  Holds Allen keys for the custom version (see photos)ReelHolder.stl      - Screw-in Reel holder for side (for both version)SideRackUpper.stl   - Side pen holder upper part (for both version)SideRackLower.stl   - Side pen holder lower part (for both version)GeneralTop.stl  - Alternative general top plateHoleBlock65.stlSquare insert with 6.5mm hole (for general version only)HoleBlock90.stlSquare insert with 9mm hole (for general version only)HoleBlock115.stlSquare insert with 11.5mm hole (for general version only)RectBlock.stlRectangular insert to put a center bar in the longer slots.
