# Advanced Material Settings [¶](https://www.orcaslicer.com/wiki/material_settings/advanced/material_advanced\#advanced-material-settings)

Advanced material settings provide additional customization options for fine-tuning the behavior of different materials in your 3D printing projects. These settings allow you to optimize print quality, adhesion, and overall performance based on the specific characteristics of each material.

## Filament start G-code [¶](https://www.orcaslicer.com/wiki/material_settings/advanced/material_advanced\#filament-start-g-code)

These settings allow you to define custom G-code commands that will be executed at the start of a print using a specific material. This can be useful for priming the nozzle, purging old filament, or performing any other necessary actions before printing.

## Filament end G-code [¶](https://www.orcaslicer.com/wiki/material_settings/advanced/material_advanced\#filament-end-g-code)

These settings allow you to define custom G-code commands that will be executed at the start and end of a print using a specific material. This can be useful for priming the nozzle, purging old filament, or performing any other necessary actions before or after printing.

## Change extrusion role G-code [¶](https://www.orcaslicer.com/wiki/material_settings/advanced/material_advanced\#change-extrusion-role-g-code)

This G-code is inserted when the [extrusion role](https://www.orcaslicer.com/wiki/developer_reference/built_in_placeholders_variables.html#extrusion-roles) is changed.

This is the material section of the feature "Change Extrusion Role G-code" that is also available in the [Process settings](https://www.orcaslicer.com/wiki/print_settings/others/others_settings_g_code_output.html#change-extrusion-role-g-code) and [Printer settings](https://www.orcaslicer.com/wiki/printer_settings/machine%20gcode/printer_machine_gcode.html#change-extrusion-role-g-code).

Tip

Read the [Printer settings](https://www.orcaslicer.com/wiki/printer_settings/machine%20gcode/printer_machine_gcode.html#change-extrusion-role-g-code) for more details and examples.
