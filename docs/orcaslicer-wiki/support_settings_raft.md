# Raft [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_raft\#raft)

[Mode](https://www.orcaslicer.com/wiki/general_settings/option_mode.html): `Advanced`.

[Variables](https://www.orcaslicer.com/wiki/developer_reference/built_in_placeholders_variables.html): `raft_layers`, `raft_contact_distance`.

Raft is a base layer that is printed under the object to improve adhesion and prevent warping. It consists of multiple layers of material that create a stable foundation for the print.

## Layers [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_raft\#layers)

Object will be raised by this number of support layers.

## Contact Z distance [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_raft\#contact-z-distance)

Z gap between object and raft. Ignored for soluble interface.
