# Support Ironing [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_ironing\#support-ironing)

[Mode](https://www.orcaslicer.com/wiki/general_settings/option_mode.html): `Advanced`.

[Variable](https://www.orcaslicer.com/wiki/developer_reference/built_in_placeholders_variables.html): `support_ironing`.

Ironing is using small flow to print on same height of surface again to make flat surface more smooth. This setting controls which layer being ironed.

## Pattern [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_ironing\#pattern)

[Mode](https://www.orcaslicer.com/wiki/general_settings/option_mode.html): `Advanced`.

[Variable](https://www.orcaslicer.com/wiki/developer_reference/built_in_placeholders_variables.html): `support_ironing_pattern`.

Select the ironing pattern to use.

## Flow [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_ironing\#flow)

[Mode](https://www.orcaslicer.com/wiki/general_settings/option_mode.html): `Advanced`.

[Variable](https://www.orcaslicer.com/wiki/developer_reference/built_in_placeholders_variables.html): `support_ironing_flow`.

The amount of material to extrude during ironing. Relative to flow of normal layer height. Too high value results in overextrusion on the surface.

## Line Spacing [¶](https://www.orcaslicer.com/wiki/print_settings/support/support_settings_ironing\#line-spacing)

[Mode](https://www.orcaslicer.com/wiki/general_settings/option_mode.html): `Advanced`.

[Variable](https://www.orcaslicer.com/wiki/developer_reference/built_in_placeholders_variables.html): `support_ironing_spacing`.

The distance between the lines of ironing.
